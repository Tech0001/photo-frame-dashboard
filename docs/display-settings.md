# Settings from the frame

Tap the bottom sidebar clock to open Display settings. Change the return-to-Today
or slideshow timer and Apply; Cancel leaves saved settings alone. The slideshow
choices include three minutes. Hold the clock for 700 ms for the original demo
controls. Settings remain open while choosing, without triggering idle mode.

On a static dashboard, choices persist in this browser. With our Hub installed,
settings are saved through its same-origin display API and shared with frames.
Server connections and secrets are not editable from this menu.

This branch works independently. With the separate themes contribution merged,
it also shows the available theme previews and saves the selected palette.
