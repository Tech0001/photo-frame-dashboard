# Anytime chores

In server admin **Chores**, choose **Anytime · all day** in a chore's routine
menu. It remains subject to the selected weekdays, and completion resets daily
like other chores.

Anytime chores appear in Morning, Midday and Evening, marked **Anytime · all
day**. The **Anytime** button shows just those chores. There is one stored chore
and one completion state, so checking it in Morning also checks it in Evening.
Today's chore rings include the current routine and Anytime chores.

Existing chores keep their assigned routine. No existing household assignments
or completion states are changed by installing this option.
