# Dashboard themes

Hold the sidebar clock to open Demo controls and choose Paper, Charcoal,
Sakura Mochi, Mechanoonna, Autumn or Winter. The choice survives reloads in this
browser. Paper keeps the original appearance. Photos and night mode keep their
own colours. Sakura Mochi changes panel shapes, borders and static backgrounds.

Palettes and original CSS adaptations credit [OldJobobo’s Sakura Mochi](https://github.com/OldJobobo/omarchy-sakura-mochi-theme)
and [HANCORE’s Mecha no Onna](https://github.com/HANCORE-linux/omarchy-mechanoonna-theme).
Their MIT notices are included in dashboard/public/licenses. No wallpapers are copied.

The separate clock-settings contribution uses these choices when installed.
Optional appearance properties clear when switching themes, including to Paper.
